## Publish on GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload the contents of this folder.
3. In **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. Open `https://YOURUSERNAME.github.io/`.

GitHub Pages supports publishing static HTML, CSS and JavaScript from a repository. Official docs: https://docs.github.com/en/pages/getting-started-with-github-pages
