# Understanding The Universe 2.0

GitHub-ready static website rebuilt around the original resources supplied for the project.

## Included
- Responsive HTML/CSS/JavaScript homepage
- Search and category filters
- Original PDFs in `pdfs/`
- Original handwritten Gamma-function image in `assets/`
- Individual resource pages in `articles/`
- Link to the original WordPress archive

## Publish with GitHub Pages
Create a public repository named `YOURUSERNAME.github.io`, upload the contents of this folder, then go to **Settings → Pages → Deploy from a branch → main → /(root)**.

The site contains no server-side code or build step.

## Important
The PDFs and handwritten image are preserved as original source material. The website does not claim that every statement inside the original documents has been independently verified.
